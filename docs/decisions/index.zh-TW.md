<a id="purpose"></a>
## 目的

架構決策紀錄（ADR）保存長期有效的跨領域決策、背景及後果，且不重寫歷史。

<a id="lifecycle-and-naming"></a>
## 生命週期與命名

ADR 使用 `adr-0001-slug.<locale>.md` 這類連續編號名稱。ADR 狀態為 `accepted` 或 `superseded`；兩者都保留於儲存庫，並由後續 ADR 取代先前 ADR。

- [命名慣例](../governance/naming-conventions.zh-TW.md)
- [文件生命週期](../governance/document-lifecycle.zh-TW.md)

<a id="current-state"></a>
## 目前狀態

目前尚無 ADR 遷移至此入口。歷史報告只有在經過刻意整理並成為符合規範的 ADR 配對後，才屬於決策紀錄。
