<a id="release-model"></a>
## Release model

Components such as the training panel use SemVer and component changelogs. Whole-project milestones use dates instead of a project-wide SemVer.

The first normalized panel release entry will be the evidenced `3.4.10`. This does not imply that panel releases `3.4.4` through `3.4.9` existed.
