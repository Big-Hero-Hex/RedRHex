# RedRHex ROS 2 deployment / RedRHex ROS 2 部署

This package runs an exported RedRHex ONNX policy through a safety-gated ROS 2 controller. Start with the [English documentation](docs/index.en.md).

此套件透過具安全閘門的 ROS 2 控制器執行匯出的 RedRHex ONNX 策略。請從[繁體中文文件](docs/index.zh-TW.md)開始。

The physical emergency stop, motor-controller watchdogs, current limits, and a lifted test fixture remain mandatory; the ROS software E-stop does not replace them.

實體急停、馬達控制器看門狗、限流與架空測試支架仍是必要條件；ROS 軟體急停不能取代這些措施。
