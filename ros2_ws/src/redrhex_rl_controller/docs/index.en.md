# ROS 2 deployment documentation

Use this component documentation to take an exported policy from offline checks to a deliberately gated hardware test.

<a id="choose-a-path"></a>
## Choose a path

- Understand the layers and ownership boundaries in [Architecture](architecture.en.md).
- Verify tensor shapes, observation order, rate, and actuator mapping in [Policy contract](policy-contract.en.md).
- Build the workspaces and prove the graph safely in [Bring-up](bring-up.en.md).
- Advance from preview to an enabled policy in [Deployment](deployment.en.md).
- Diagnose a blocked gate or stale signal in [Troubleshooting](troubleshooting.en.md).

The shared [project policy contract](../../../../docs/reference/policy-contract.en.md) is the cross-project source for the trained model interface.
