# ROS 2 部署文件

使用此元件文件，將匯出的策略從離線檢查推進至刻意設有閘門的硬體測試。

<a id="choose-a-path"></a>
## 選擇路徑

- 從[架構](architecture.zh-TW.md)了解分層與責任邊界。
- 從[策略契約](policy-contract.zh-TW.md)核對張量形狀、觀測順序、頻率與致動器映射。
- 依照[啟動](bring-up.zh-TW.md)建置工作區並安全證明 ROS graph。
- 依照[部署](deployment.zh-TW.md)從預覽推進至啟用策略。
- 以[疑難排解](troubleshooting.zh-TW.md)診斷被阻擋的閘門或逾時訊號。

跨專案的訓練模型介面以共用[專案策略契約](../../../../docs/reference/policy-contract.zh-TW.md)為準。
