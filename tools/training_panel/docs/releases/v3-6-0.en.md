<a id="release"></a>
## Release

Training Panel 3.6.0 improves the local Mother interface while preserving the V3.5 training-insight behavior and the independently versioned `3.4.10-sync-health` remote Child/worker contract.

<a id="errors"></a>
## Visible action failures

- Failures from Rewards, Terrain, Convergence, Activity, and Control Center are reported in the active view instead of being written into an unrelated History status line.
- API failures now return structured failure responses instead of allowing handler exceptions to close the connection without a usable response.

<a id="navigation"></a>
## Navigation and run actions

- The current view and selected run are stored in the URL, preserving context across refreshes and shareable links.
- Resume to Train, Tweak, and Compare are grouped in the run-card overflow menu; Stop remains directly accessible.
- Tooltips appear on keyboard focus as well as pointer hover.

<a id="state"></a>
## Loading and connectivity state

- Panels display loading skeletons until their first fetch completes instead of presenting in-flight data as empty.
- The top bar shows whether the Mother is receiving backend responses and how old the latest response is.

<a id="upgrade"></a>
## Upgrade notes

Restart the local Mother and allow the browser to load the `3.6.0-panel-ux` assets. This release does not require a Supabase schema migration and does not advance remote Child cache keys or worker schema versions.
