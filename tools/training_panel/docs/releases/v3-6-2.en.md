<a id="release"></a>
## Release

Training Panel 3.6.2 makes the Train form mode-aware so operators see and submit only the controls used by the selected standard or Sensor V2 workflow.

<a id="route-specific-controls"></a>
## Route-specific controls

- **Standard PPO — No Distillation** shows one Iterations field and hides all F1/F2/F3 fields.
- **Sensor V2 — Full F1 → F2 → F3 Pipeline** shows the three stage iteration fields and hides the unused task, single-stage iteration, checkpoint, reward, and terrain controls. Physics remains available.
- Advanced F1, F2, and F3 single-stage modes relabel the one Iterations field for the selected stage. F2 and F3 mark their compatible source checkpoint as required; F1 keeps resume optional.
- A mode summary explains the selected workflow, and the common end-to-end modes are separated from advanced single-stage recovery workflows.

<a id="request-and-presets"></a>
## Request and preset behavior

The browser omits F1/F2/F3 iteration values unless the full pipeline is selected and omits the single-stage iteration value for the full pipeline. Sensor V2 requests also omit the fixed task and unused reward and terrain preset fields while retaining the selected physics profile. Smoke and debug defaults update whichever iteration controls are active. The backend command and checkpoint-kind contracts are unchanged.

<a id="upgrade"></a>
## Upgrade notes

Restart the local Mother and load the `3.6.2-route-clarity` assets. This local UI release does not change the independently versioned `3.4.10-sync-health` remote Child/worker protocol, Supabase schema, training commands, or existing run records.
