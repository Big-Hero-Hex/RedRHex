<a id="release"></a>
## Release

Training Panel 3.5.0 為本機 Mother 新增 live training insight 與 launch provenance。此版本接續有證據的 3.4.10 consolidated release，且不改變獨立部署的 remote Child/worker protocol version。

<a id="progress"></a>
## Progress 與 curve

- 執行中的 card 會從最新完整 process-log block 解析 iteration、completion percentage、ETA、throughput、mean reward 與 episode length。
- Run detail 直接從本機 TensorBoard scalar event file 繪製 mean reward 與 episode-length curve，不需要外部 charting service。
- Volatile progress update 不會覆寫 durable run metadata timestamp。

<a id="divergence"></a>
## Divergence monitoring

- Convergence monitoring 會偵測 non-finite scalar value 與 reward 持續崩塌。
- Detector 可發送 Discord 通知，並在 run history 記錄 kind、reason 與 iteration。
- Automatic stop 是 opt-in。預設 action 僅通知，讓操作人員先依各 task 的 reward scale 驗證 threshold。

<a id="reproducibility"></a>
## 可重現性

- 每個面板啟動的 run 會記錄啟動時可取得的 Git commit、branch 與 dirty state。
- Train seed 留白現在代表面板選擇並記錄 random seed，不再依賴未記錄的 environment default。

<a id="upgrade"></a>
## 升級說明

Pull 此 release 後 restart 本機 Mother。既有 run record 仍可讀取，但不會補上當時啟動時無法取得的 provenance。選擇 automatic-stop action 前，先 review divergence setting。
