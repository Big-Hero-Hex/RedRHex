<a id="release"></a>
## Release

Training Panel 3.6.1 prevents the known Explicit torsion-spring numerical runaway from entering new policy training while preserving both spring implementations and historical run identity.

<a id="spring-safety"></a>
## Spring safety boundary

- New policy runs provisionally default to Native.
- Explicit is visible but disabled in Train, and CLI/API/process guards reject policy training before history creation, simulator launch, or process spawn.
- Explicit remains available through deterministic spring-release characterization; Native remains uncalibrated and is not selected for production.
- The full Sensor V2 pipeline forwards the selected backend unchanged through F1, F2, and F3.

<a id="provenance"></a>
## Checkpoint provenance

Stamped uncalibrated checkpoints now reject backend mismatch. Existing metadata-free runs keep the historical Explicit fallback rather than being silently relabeled. Play, video, and export continue to resolve a run's recorded backend.

<a id="physics-editor"></a>
## Physics editor corrections

The torsion-spring editor now matches runtime defaults: damping is zero, actuator-path effort and velocity limits are nonbinding, and stable `damper_0` through `damper_5` aliases remain. Labels distinguish legacy uniform compatibility values from per-spring parameters and warn that armature requires physical evidence.

<a id="upgrade"></a>
## Upgrade notes

Restart the local Mother and load the `3.6.1-spring-safety` assets. If remote operation is enabled, pause job acceptance and explicitly restart the remote worker from Control Center; restarting Mother alone does not replace an already-running worker, and the fresh worker supplies the Native default for existing `3.4.10-sync-health` Child requests that omit the field. Verify the new worker heartbeat before accepting jobs again. Existing Explicit checkpoints are not converted to Native. This release does not change the independently versioned remote Child/worker protocol and does not select a deployable spring backend.
