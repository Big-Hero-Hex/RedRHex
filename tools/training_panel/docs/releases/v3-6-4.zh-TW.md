## 版本與日期

- 版本：`3.6.4-drive-export`
- 日期：2026-08-14

<a id="summary"></a>
## 摘要

Training Panel 3.6.4 在 Mother History 新增 one-touch Google Drive 匯出，可處理最新影片或選定 checkpoint 的影片。上傳在背景執行，未變更且已完成的匯出會直接重用，並回傳 private Drive view link，不會改變檔案分享設定。

<a id="changes"></a>
## 變更

- Mother 會回報本機 rclone 與必要的 `redrhex-drive:` remote 是否可用，不會暴露 credential。
- History video panel 會依每個錄製影片顯示 setup、uploading、completed 與 retry 狀態。
- Exporter 會驗證 run ownership、寫入 `RedRHex Videos/<run-id>/<video-filename>`、保存 lifecycle evidence、合併 concurrent click，並在 restart 後將 stale 工作標示為 interrupted。
- Rclone 不透過 shell 執行。`copyto` 負責上傳，`lsjson --stat` 回傳 file ID；不會使用 public-link command。

<a id="compatibility-and-migration"></a>
## 相容性與遷移

在 training PC 安裝並設定一次 rclone，remote 名稱必須完全是 `redrhex-drive`，然後重新啟動 Mother。既有 run record 不需 migration；Drive export metadata 是 additive。此 local release 不改變 training command、`3.4.10-sync-health` remote Child/worker protocol、Supabase schema 或 Google Drive 分享權限。

<a id="verification-and-evidence"></a>
## 驗證與證據

Unit coverage 涵蓋 readiness、path containment、sanitized destination、deduplication、concurrent click、success/failure persistence、token redaction、restart reconciliation 與 HTTP status mapping。Local Playwright coverage 涵蓋 setup 缺失、latest/checkpoint request、background state、private link opening、retry state，以及 mobile History layout。
