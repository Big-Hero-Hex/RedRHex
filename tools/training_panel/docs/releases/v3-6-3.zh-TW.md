<a id="release"></a>
## Release

Training Panel 3.6.3 修復 History 的 run comparison、移除介面回報未實際執行工作的狀態，並讓 run list 可用鍵盤操作。

<a id="comparison"></a>
## Run comparison

Comparison 現在繪製在自己的 panel，不再取代 run details panel。先前關閉 comparison 會破壞 details 元素，導致之後每次 detail render 都失敗，History poll 也停止更新，必須重新載入頁面。現在可用 `Escape` 關閉 comparison，被比較的 run 會在列表標示，對其他 run 按 **Compare** 則會替換被比較的欄位。

<a id="destructive-actions"></a>
## 破壞性操作

只有在操作者確認後，run 才會標示為刪除中；確認對話框仍開啟時，卡片不再自行變灰。Bulk deletion 現在需要輸入 `DELETE` 確認，刪除多個 run 不再比刪除單一 run 容易。Folder 的建立、重新命名與移除改用 Panel 的確認對話框，不再使用瀏覽器對話框。

<a id="run-list"></a>
## Run list 與 filter

- Search、status、sort 與 folder 選擇會在重新載入後保留；當 filter 隱藏了 run 時會出現 **Clear filters**。
- 套用 filter 時，run 數量顯示為 `N of M`。
- Search 也會比對 folder 名稱、note 內容與 preset id。
- 依 status 排序時，running、stopping 與 queued 會排在已結束的 run 之前，不再依字母排序。
- `/` 聚焦 search，`j`/`k` 與方向鍵移動選擇，`Escape` 清除 search 欄位。
- Checkbox 支援 shift-click 範圍選取，也可把 run card 拖曳到側邊欄 folder 進行移動；拖曳已選取的 run 會移動整組選取。
- 拖曳會直接說明結果：游標帶著 run 名稱或選取數量，拖曳期間所有可接收的 folder 都會標示，已包含全部拖曳 run 的 folder 會變淡並拒絕放下，游標所在的 folder 顯示 `Move N runs here`，接收的列則在下方列表變動時確認移動完成。
- Bulk toolbar 的控制項固定存在，只切換 disabled 狀態，因此勾選 run 不會改變 toolbar 高度或使下方列表位移。
- Folder 列改為可用鍵盤操作的 button，長名稱會換行而不再被截斷，並在拖曳時標示為 drop target。
- Run list 捲動時，search 與 filter 列會保持顯示。
- Running run 的卡片只繪製一個 progress bar，先前會繪製兩個。

<a id="run-details"></a>
## Run details 與通知

切換選擇時，未儲存的 notes 會依 run 保留並標示為未儲存草稿；帶著未儲存 notes 離開頁面會先提示。相對時間會附上絕對時間。Run 進入結束狀態時會發出 History 通知，而不再只有新建立的 run 才通知。

<a id="upgrade"></a>
## 升級說明

重新啟動本機 Mother 並載入 `3.6.3-history-clarity` assets。此本機 UI release 不會改變獨立版本化的 `3.4.10-sync-health` remote Child/worker protocol、Supabase schema、training command 或既有 run record。
