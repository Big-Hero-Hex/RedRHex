<a id="release"></a>
## 版本

Training Panel 3.6.2 讓 Train form 能依 mode 調整內容，操作人員只會看到並送出所選 standard 或 Sensor V2 workflow 會使用的 controls。

<a id="route-specific-controls"></a>
## Route 專屬 controls

- **Standard PPO — No Distillation** 只顯示一個 Iterations field，並隱藏所有 F1/F2/F3 fields。
- **Sensor V2 — Full F1 → F2 → F3 Pipeline** 顯示三個 stage iteration fields，並隱藏不使用的 task、single-stage iteration、checkpoint、reward 與 terrain controls；Physics 仍可使用。
- Advanced F1、F2 與 F3 single-stage modes 會依所選 stage 重新標示唯一的 Iterations field。F2 與 F3 會把相容的 source checkpoint 標為 required；F1 的 resume 仍為 optional。
- Mode summary 會說明目前所選 workflow；常用的 end-to-end modes 也會和 advanced single-stage recovery workflows 分開。

<a id="request-and-presets"></a>
## Request 與 preset 行為

只有選擇完整 pipeline 時，browser 才會送出 F1/F2/F3 iteration values；完整 pipeline 也不會送出 single-stage iteration value。Sensor V2 request 也會省略固定 task，以及不使用的 reward/terrain preset fields，同時保留所選 physics profile。Smoke 與 debug defaults 會更新目前生效的 iteration controls。Backend command 與 checkpoint-kind contracts 均未改變。

<a id="upgrade"></a>
## 升級說明

Restart 本機 Mother，並載入 `3.6.2-route-clarity` assets。這個 local UI release 不會改變獨立 version 的 `3.4.10-sync-health` remote Child/worker protocol、Supabase schema、training commands 或現有 run records。
