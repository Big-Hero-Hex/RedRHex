<a id="release"></a>
## Release

Training Panel 3.5.0 adds live training insight and launch provenance to the local Mother. It follows the evidenced 3.4.10 consolidation and does not change the independently deployed remote Child/worker protocol version.

<a id="progress"></a>
## Progress and curves

- Running cards show iteration, completion percentage, ETA, throughput, mean reward, and episode length parsed from the latest complete process-log block.
- Run details draw mean reward and episode-length curves directly from local TensorBoard scalar event files without an external charting service.
- Volatile progress updates do not overwrite durable run metadata timestamps.

<a id="divergence"></a>
## Divergence monitoring

- Convergence monitoring detects non-finite scalar values and sustained reward collapse.
- Detection can send a Discord notification and records the kind, reason, and iteration in run history.
- Automatic stopping is opt-in. The default action is notification-only so operators can validate thresholds against each task's reward scale.

<a id="reproducibility"></a>
## Reproducibility

- Every panel-launched run records the Git commit, branch, and dirty state available at launch.
- A blank Train seed now means the panel chooses and records a random seed instead of relying on an unrecorded environment default.

<a id="upgrade"></a>
## Upgrade notes

Restart the local Mother after pulling this release. Existing run records remain readable but do not gain provenance that was unavailable when they launched. Review divergence settings before selecting the automatic-stop action.
