<a id="release"></a>
## Release

Training Panel 3.4.10 是目前 Python version、mother UI、child asset、heartbeat 與 worker schema 所代表的合併 release。此紀錄接續有證據的 3.4.3 歷史；不虛構 3.4.4 至 3.4.9 的個別 release。

<a id="sync"></a>
## Sync 與 history

- Machine-scoped child query 與明確 clearing 讓 run、job、artifact、name、note 與 folder 保持一致。
- Folder 與 run deletion tombstone 防止 stale Supabase row 重新建立已刪除本機狀態。
- Active reward/terrain selection 與 per-run override snapshot 保持可區分；手動 training 沒有 `--panel_overrides` 時不再使用 stale panel file。
- History persistence 使用 lock 與 atomic replacement。

<a id="operations"></a>
## 操作

- Mother queue 序列化 training、playback、video 與 ONNX export，並在遠端暴露 queue/GPU-lock state。
- Terrain preset 與儲存的 run terrain 一致套用到 training 及忠實 playback/video。
- Worker heartbeat 與 UI version surface 使用 `3.4.10-sync-health`。

<a id="deployment"></a>
## 部署

- Deploy 頁面加入 export integrity、ONNX/runtime、Torch parity、policy-contract、safety-fault、可選 ROS mock 與 advisory MuJoCo 階段。
- Deployment validation 在 panel Python 執行；Isaac action 保持在 Isaac environment。
- Contract parity 將 ROS policy loop 對齊 60 Hz 與目前 ABAD normalization/limit。

<a id="upgrade"></a>
## 升級說明

Pull 完整 release，並一起 restart mother 與 worker。若 deployed schema 早於 folder/sync 新增內容，重新套用 `tools/training_panel/supabase/schema.sql`。確認 asset URL 帶有 3.4.10 cache key 後才清 browser cache。Machine token 必須保持私密。
