- Version: `3.8.0-autopilot-preview`
- Date: 2026-08-14

<a id="summary"></a>
## 摘要

Training Panel 3.8.0 新增預設關閉、僅供 simulation 使用的 Autopilot preview，用於 durable bounded reward campaign。Human 先建立並 arm 確切 goal 與 budget；外部 ChatGPT advisor 可以提出一個 allowlisted weight change；execution、evaluation、ranking、budget、recovery 與 success authority 仍由 panel 負責。

<a id="changes"></a>
## 變更

- Mother 新增 Autopilot workspace，用於 exact command preview、baseline/tunable selection、budget review、explicit arming、lifecycle 與 GPU/connector status、candidate lineage、evaluation gate、paired-seed evidence、campaign-owned stop control 與 patch export。
- SQLite WAL state、append-only event、revision/idempotency check、SHA-256 addressed artifact、restart reconciliation、immutable per-run profile、exact checkpoint loading 與 host GPU serialization，讓 unattended local work 不會造成 duplicate launch。Policy-only baseline 由已記錄的 run、checkpoint iteration 與 SHA-256 選取。Campaign training 只記錄 iteration cap 綁定的 final checkpoint receipt，包括沒有 monitor 的 recovery，而不使用 History 的 latest-file scan。已安裝 dependency file 與 editable Git source state 都會以內容綁定，且 V1 會拒絕 non-default terrain override。
- Advisor candidate 限於 human 縮窄後、以 campaign-start value 計算的有限 80/90/100/110/120% reward lattice。Decision context 會暴露 lattice availability、attempted move、leader delta、evidence ID 與 remaining budget，但不包含 raw log 或 local path。
- Standard PPO control/candidate trial 後會自動執行 exact-checkpoint command-sweep evaluation。Evidence identity 會綁定 evaluator 記錄的 environment 數、600 個 step、確切 1/60 秒 control interval 與推導出的 duration；每個 command/environment 都必須提供完整 horizon，command success duration 也必須與 episode ratio 一致。Command、episode、summary 與 evaluated-report artifact 都不可變，restart 後與 confirmation 前會重新驗證，因此缺漏、截斷或遭竄改的 evidence 都會 fail closed。只有 deterministic hard gate 與 three-seed confirmation 能產生 `simulation_goal_met`。
- Controller failure 會在向 active work 發出 signal 前保存只屬於該 campaign 的 stop intent。後續 tick 或 restart 會完成停止、cumulative GPU accounting 與 fail-closed terminal transition，不會遺失 process identity。
- `redrhex-autopilot` plugin 提供 narrow stdio/loopback Streamable HTTP MCP adapter 與 scheduled-advisor skill。它不能 arm、resume、擴大 budget、執行任意 command、套用 source change、export/deploy policy、操作 hardware，或停止無關工作。
- Legacy Reward Agent JSON 會保留並匯入為不可 arm 的 reference。Standalone Reward Agent workflow 仍可使用，但不是 Autopilot advisor 或 success authority。
- Mother Settings 現在會分開呈現 Google account 與 video-folder 選項。Operator 可貼上已連線帳號能存取的 Google Drive folder URL，或輸入 My Drive path；folder ID 與 optional legacy resource key 只留在本機，export 維持 private，account reconnect workflow 由 **Change Google account** 負責。

- Physics 頁面新增以 deploy URDF 建構的機器人預覽，並由 `GET /api/physics/robot-geometry` 提供。它反映的是正在編輯的 preset 而非機器人狀態：扭轉彈簧 rest position 會轉動對應腿部，質心標記跟隨其 offset field，contact friction 會為地面上色。選取腿部沿用既有搜尋篩選，無法以空間呈現的量則以文字回報。繪製使用置於 `static/vendor/` 的釘選版 three.js，維持面板無 bundler 且可離線；沒有 WebGL 時降級為可互動的俯視示意圖。此預覽會回報 field 清單中右側腿部名稱與 URDF 安裝位置不符；canonical joint index、actuator 分組與 tripod 歸屬皆不受影響。

<a id="compatibility-and-activation"></a>
## 相容性與啟用

Autopilot 只支援 ForwardFast stage 1 與 Direct stage 1–5；不包含 Sensor V2。Mother 必須以 `REDRHEX_AUTOPILOT_ENABLED=1` 啟動，否則功能保持停用。Panel 與 MCP adapter 應維持 loopback binding，bearer/tunnel credential 必須留在 repository 之外。

此 release 不改變 Supabase schema 或 Child/worker contract：`REMOTE_PROTOCOL_VERSION` 仍為 `3.7.0-remote-parity`，也不提供 remote campaign control。它不會 provision ChatGPT Scheduled、OpenAI Secure MCP Tunnel、Platform tunnel ID/permission 或 runtime credential。Operator 必須另外設定這些外部 service，才能取得每 15 分鐘一次的 unattended advisor visit；未設定時，active local work 會正常完成，而 campaign 會安全等待。

<a id="rollout-and-boundary"></a>
## Rollout 與邊界

在 target environment 通過 fake-advisor 與 restart test 前，請保持 capability 關閉。之後依序執行 shadow proposal、四個 trial 的 ForwardFast pilot、restart recovery 與完整 opt-in qualification campaign，再啟用 Direct stage 2–5。最強的 terminal claim 是 `simulation_goal_met`；policy export、deployment readiness、hardware promotion 與 robot actuation 仍是分開且由 human governance 的 workflow。

<a id="verification-and-evidence"></a>
## 驗證與證據

Repository coverage 涵蓋 schema、有限 reward lattice、exact baseline identity、default-terrain enforcement、state transition、budget、idempotency、deterministic gate/ranking、immutable-report tamper detection、controller failure-stop recovery、fake unattended process loop/recovery、HTTP/MCP scope、browser draft/lifecycle behavior、雙語文件，以及既有 Training Panel/Reward Agent behavior。Real Isaac 與外部 Scheduled/tunnel pilot 仍是明確的 rollout gate；此 preview 不宣稱 repository test 已 provision 或完成它們。
