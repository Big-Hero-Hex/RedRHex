<a id="summary"></a>
## Summary

Training Panel 3.6.4 adds one-touch Google Drive export for the latest or selected checkpoint video in Mother History. Upload runs in the background, reuses an unchanged completed export, and returns a private Drive view link without changing file sharing.

<a id="changes"></a>
## Changes

- Mother reports whether local rclone and the required `redrhex-drive:` remote are available without exposing credentials.
- The History video panel shows setup, uploading, completed, and retry states for each recorded video.
- The exporter validates run ownership, writes `RedRHex Videos/<run-id>/<video-filename>`, persists lifecycle evidence, coalesces concurrent clicks, and marks stale work interrupted after restart.
- Rclone runs without a shell. `copyto` performs the upload and `lsjson --stat` returns the file ID; the public-link command is not used.

<a id="compatibility-and-migration"></a>
## Compatibility and migration

Install and configure rclone once on the training PC, using the exact remote name `redrhex-drive`, then restart Mother. Existing run records need no migration; Drive export metadata is additive. This local release does not change training commands, the `3.4.10-sync-health` remote Child/worker protocol, Supabase schemas, or Google Drive sharing permissions.

## Verification and evidence
