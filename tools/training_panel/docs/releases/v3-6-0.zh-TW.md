<a id="release"></a>
## Release

Training Panel 3.6.0 改進本機 Mother interface，同時保留 V3.5 training-insight 行為與獨立 version 的 `3.4.10-sync-health` remote Child/worker contract。

<a id="errors"></a>
## 可見的 action failure

- Rewards、Terrain、Convergence、Activity 與 Control Center 的 failure 會回報於 active view，不再寫入無關的 History status line。
- API failure 現在會回傳 structured failure response，不會因 handler exception 關閉連線而沒有可用回應。

<a id="navigation"></a>
## 導覽與 run action

- 目前 view 與 selected run 會保存於 URL，refresh 與分享連結都能保留 context。
- Resume to Train、Tweak 與 Compare 收納於 run-card overflow menu；Stop 維持直接可用。
- Tooltip 會在 keyboard focus 與 pointer hover 時顯示。

<a id="state"></a>
## Loading 與 connectivity state

- Panel 會在第一次 fetch 完成前顯示 loading skeleton，不會把 in-flight data 顯示成 empty。
- Top bar 會顯示 Mother 是否收到 backend response，以及最新 response 經過多久。

<a id="upgrade"></a>
## 升級說明

Restart 本機 Mother，並讓 browser 載入 `3.6.0-panel-ux` asset。此 release 不需要 Supabase schema migration，也不會推進 remote Child cache key 或 worker schema version。
